# 1つのウォレット、2種類の委任

Cardanoのホルダーが混同しやすい2種類の委任（ステーキングPOOL委任 / DRep委任）を、
実際に動かして体感するインタラクティブなページです。

## 内容

- **比較表** — 2つの委任は何がどう違うのか
- **勢力図 + 投票シミュレーション** — 人数と投票力の逆転を体感する
- **可決ゲーム** — あなたの20%をどう使うかで結果が変わる
- **営業ゲーム** — 提案者の立場から見た「誰に働きかけるか」
- **プール委任ゲーム** — 飽和度と、運営者停止時の影響範囲
- **ロジックツリー** — 2つの委任それぞれの詳細解説（16項目）

## 注意

ページ内のシミュレーションはすべて**架空のモデル**です。
母数を100人に単純化し、人数やパーセンテージは分かりやすさを優先して調整しています。
実在のDRepや事業者、実際の提案を再現したものではありません。

ただし「上位のごく少数が大きな割合を占める」という力の偏り方だけは、
実際のCardanoのDRep分布を参考にしています。

## 出典

仕組みの説明は CIP-1694 および Cardano Developer Portal / Cardano Docs の記述に基づいています。

最新の値はチェーン上の値を確認してください。
